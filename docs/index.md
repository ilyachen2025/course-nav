!!! tip "怎么用这个页面"
    - **搜标题**：点右上角放大镜，或按 <kbd>/</kbd> 或 <kbd>S</kbd>，输入关键词（中文已开分词，输入"储能"能命中"储能变流器"）。
    - **按分类找**：左侧导航栏切换五个分类，每个分类页是卡片网格。
    - **打开资料**：点卡片底部的「打开资料」，在新标签页跳转。
